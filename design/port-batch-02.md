inside each retained leaf. The existing Java workflow demonstrates that selection policy
changes the region layout while palette/content edits reuse it. The motivating evidence
and measured example settings remain those in the frozen quadrant contract and CP4
review; this batch adds no parameter defaults or recommended ranges.

The result contains shared endpoint bounds and creation IDs in mutation order. It does
not draw, clip, assign content or recreate source palettes. Preserve fractional selection
intervals, TL/TR/BR/BL append order followed by parent removal, and the distinction between
creation IDs and live indices. Longer runs share replacement history, not final-array prefixes.
