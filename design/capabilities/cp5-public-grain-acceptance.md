# CP5 public GrainMarks acceptance

Root implementation plan after contract freeze. The public Java implementation and example
must be validated separately from the accepted private JavaRandom/weighted-sum investigation.
No additional private render is needed. This plan does not claim an installed run yet.

## Entry point and edits

Install the next local Java distribution and open GrainMarks in Processing. Its baseline
uses one supplied triangle and TrianglePoints2D.seeded. B switches to two editable caller
coordinate expressions through TrianglePoints2D.map. The example's Java Random stream is
explicitly separate from the public xoshiro stream; neither route claims source replay.
N changes area-based count allocation from density0.1 to0.2. These are example constants,
not recommended ranges. C and M reuse the exact completed composition without rebuilding
its regions. X splits thirteen CP4 rectangles into 26 triangles and applies the same grain.
The darker five-colour palettes address the private transfer image's faint yellow/teal.
Actual rendered legibility still needs root inspection.

The small area/count calculation applies only to the authored 640-square canvas geometry;
it is not advertised as a robust arbitrary-triangle area function. Before sampling, every
count is computed and the whole example is limited to160000 retained points. There is no
per-point allocation during drawing. Explicit biased input pairs are released after map.

## Required pure and native evidence

- Execute all59 frozen fixture cases against the actual Java class, not the Python oracle.
- Verify detached inputs/exports, numeric carriers, index/error precedence and atomic writes.
- Verify actual seeded prefix and mapped equivalence; inspect exact scalar interpolation,
  single sqrt per point, two RNG draws, zero-count branch and validation/allocation order.
- Measure tiny, motivating and bounded stress workloads; include explicit-map input memory
  separately from retained output memory where measurable. Do not equate packed payload
  bytes with total JVM retained heap or promise allocation success near representation limits.
- Compile both plain Java composition and the actual PDE with official preprocessing.
- Build and test extracted0.5.0 JARs; ensure class origins are those installed artifacts.
