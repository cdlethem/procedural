# Recorded controls and contour marks

Root admits one pure scalar-timeline query, not a media framework or font engine.
An artist can change which recorded feature drives mark radius, spacing or color,
change the word while keeping the feature sequence, and reuse the same controls for
non-audio data. The query removes bracket search, exact-knot handling, interpolation,
gap policy and independent channel mappings. Its detached ordered scalar output is
usable by any existing mark/path operation. Inline lerp remains an alternative for a
single bespoke animation; repeated multi-channel mapping and gap handling justify this
small reusable boundary. No retained cache, media permission, FFT or clock enters it.

The external corpus record `joshua-davis-nikelab-21-mercer-usopen-tennis-deconstructed`
links [Davis's project](https://joshuadavis.com/NikeLab-21-Mercer-USOpen-Tennis-Deconstructed/):
recorded tennis audio controls court-derived graphics. That supports the task, not our
interpolation, feature extraction or type motif. The manifest is
`evidence/external-art/2026-09/corpus.json`, SHA-256
`c25caa8edf07e11bf1f97cc5a1d70dd65a915620992bc0b3d3746c80ae59d209`.
Golan Levin's Eyecode and Manual Input Workstation require computer vision and event
segmentation; scalar mapping does not close those gaps. Growing Data's growth algorithm
is similarly outside this slice. No complete original is newly claimed recreated.

p5 already supplies `Font.textToContours`. Root rejects a public wrapper restricted to
one known font: extraction remains explicit editable host code, with the licensed
GlyphMarks asset, pinned p5 runtime, text-state restoration and glyph coverage checked
by the native study. Contours remain separate; no inferred hole classification, shaping
or fill topology. The font license stays with the existing asset; no new system font.

The original study uses project-authored deterministic PCM, a documented RMS extraction
and hashed derived scalar data. It must call this a synthesized signal, not a recording
of a real performance. Reset/reload use explicit logical time; source data and geometry
must survive independent palette edits. A non-audio series and a path-mark consumer
provide contrasting transfer cases. Native/installed execution and visual quality follow
contract/core checks. The baseline query adds no live microphone or camera acquisition.
Optional live acquisition remains separate unfinished G work, with explicit user action,
permission failure, track teardown and bounded observations before support can be claimed.

Time is seconds from the caller's origin; maxGap is an authored policy. Required controls
have no defaults or recommended ranges. Runtime cost is full validation plus logarithmic
bracket search and one pass over mappings, not an implicit real-time performance promise.
