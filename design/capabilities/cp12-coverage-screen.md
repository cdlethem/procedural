## Cost and admission question

A band walker could remove proposal/rejection traversal and retained accepted-path storage
from artist code. Existing palette and drawing code can provide presentation. However,
public semantics would introduce at least band tolerance, attempt versus accepted-move work,
proposal steering, field sampling and private RNG behavior. The source's ten-million-attempt
scene also creates a real performance and memory obligation. Replacing its steering with an
arbitrary easier algorithm would weaken the very recreation gain being assessed.

Current result: **zero demonstrated new original recreations, one projected original,
no established additional independent composition pattern**. This does not automatically
reject a rare valuable idiom. Root must justify its value and manageable interface directly,
or defer it in favour of a stronger capability; a presumed large family count is unavailable.
Luna's bounded identity/source/variant brief remains the next input to that decision.
