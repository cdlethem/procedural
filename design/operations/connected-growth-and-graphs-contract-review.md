# Connected growth and graph contract review

Root freezes these four contracts after an independent Astra architecture proposal and Sol
review of all53 analytical cases. Sol independently recomputed successful relative-neighborhood
fixtures with exact Fraction arithmetic and checked the work formulas, force signs, backtracks,
lineage, bridge ordering and cap cases. Root inspected the normative stage/primitive order.

Resolved choices: finite-edge rather than point-only contact; atomic final-state backtracking,
not a swept-collision promise; clamped nonnegative contact falloff if norm rounding lands at
the force-range boundary; target growth before this call's force evaluation; midpoint refinement
with exact rest halves and explicit ID lineage; no mass/energy conservation through remeshing.
Bridge candidates with fewer than two hits return a detached no-op. Collinear overlap always
errors, including a repeated connector, so no unreachable duplicate-link no-op is promised.

Root moved the transcendental right-angle bend case to a separate toleranced analytical oracle.
Shared exact-json fixtures contain only exact outputs/errors. No implementation generated
these expected results. This contract freeze permits implementation; it is not native, artist
recreation or target-support acceptance.

Root implementation clarification (17 September): graph embedding constrains node-coordinate uniqueness and edge-edge contacts. Isolated nodes may lie on existing edges; no N*E vertex-edge exclusion is introduced. Only old edge endpoints are reused at hits. A newly rounded hit coinciding with any other node, including an isolated one, is REPRESENTATION_COLLAPSE.
