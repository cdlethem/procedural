# Admit a retained gradient-path dependency for CP2

Root admits `path.gradient-trace-2d` for contract preparation after Sol's architecture
challenge and both reviewers' inspection of the four registered design images. See
[architecture decision](../capabilities/cp2-architecture-decision.md),
[operation proposal](gradient-path-proposal.md), and
[visual decision](../../evidence/parameter-experiments/cp2-path-choice/decision.md).
This is not contract approval or implementation acceptance.

The artist can grow a continuous trajectory, retain it, redraw it with perpendicular
marks, and recolour those marks without redoing movement. The operation owns repeated
current-position field sampling and advancement. A complete immutable packed path is the
first result. No public one-step helper, generic field executor or streaming-generation
route is admitted. The existing gradient field is the only initial carrier. Binary64
feedback is distinct from downstream rendering precision, with same-target exact replay
and per-fixture cross-target tolerance work still required in the contract.

Ciserp#0, mantel#0 and natalata#0 motivate integration, but their parent descriptions also
include rendering, field algorithms and modulation not computed by this new operation.
They remain in their existing ledger locations and statuses. Limo002#1 is the contrasting
compound emitter, not a single trajectory merge. The admission binds those exact candidate
records and accounts for their remainders instead of claiming whole-candidate equivalence.
No source sketch code was copied.

The finer-field experiment reveals long horizontal runs; the field is accepted for the
legible base wandering-path task, not isotropy, “organicness,” simplex equivalence or a
universal scale recommendation. Source-specific field reproduction remains open. The
public example must preserve useful substitution of marks and make these controls honest.

Inputs are explicit seed-only gradient configuration, a start, finite step count/distance,
coordinate scale/offset and angle base/scale. Count authorizes eager work only on the trace
call. The result contains N+1 positions and N sampled headings, with mark attachment and
progress/envelope choices left to the caller. Step distance is nonnegative: this is the
forward fixed-distance operation, with zero a stationary degenerate sequence. Negative
angle/coordinate scales remain mathematically meaningful mappings. Static input errors,
representational limits, dynamic indexed failures, output ownership, sampling order and
per-field numerical comparisons must be frozen in the catalog before ports begin.

This admission does not promote the old `path.flow-trace` family into a contract, reduce
its unresolved members, reject rare families, or complete I2. The next work is a reviewed
catalog entry with distinguishing feedback/error/ownership fixtures, then the public
implementation and four-target native edit/reproduction checks.
