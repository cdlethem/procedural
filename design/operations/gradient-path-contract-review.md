# Gradient path contract review

Status: approved for implementation by root following independent Sol review.
The normative contract is `catalog/operations/gradient-path.json`. Public implementations
and native capability acceptance remain unvalidated.

The operation removes feedback integration from artist code and retains points and
headings for independent lines and attached marks. Root accepts one eager gradient-field
trace, explicit configuration, packed binary64 output, detached ownership and indexed
errors. No generic callback protocol or second streaming API is admitted.

Sol challenged input carriers, export failure ownership, provenance relationships and
numerical fixtures. The final contract specifies accepted containers per language;
failed exports preserve the original path; motivating candidates remain dependencies
with explicit composite remainders rather than whole-computation merges.

The reviewed fixture plan contains 32 short/error cases and 20 sparse long cases. It
covers evolving-position feedback, multiple seeds, stationary paths, separate rounding
versus fused multiply/add, raw-bit prefix, canonical positive zero, final-endpoint
non-query and indexed failures. Native checks must additionally prove detachment,
access/validation order, unchanged output on failure and resource-error classification.

Exact cases require zero tolerance. Named noncardinal cases permit absolute position
and heading errors of 1e-9, based on the three-host diagnostic (maximum position distance
below 4.43e-12) and 20 Android ART cases matching Java bits in all six measured fields.
These are fixture criteria, not arbitrary-descriptor bounds or renderer guarantees.
The final `evidence/investigations/cp2-numerics-android.json` corrects the copied Android
scope sentence, preserves the shared matrix hash, and records current runner, DEX and
runtime hashes. This closes Sol's last evidence-text condition.

Public examples must demonstrate manageable configuration and independent movement,
mark-extent and palette edits. The private four-image experiment established the design
boundary but does not establish public port conformance. Preserve its finer-field
horizontal-locking limitation; no simplex equivalence, isotropy or public useful-range
claim is approved. Follow the capability reproduction acceptance before claiming support.
