# Radial profile surface contract review

Root accepts the operation semantics and source-generated fixture approach for Java-first
implementation. This is not a delivered capability or native target acceptance.

The artist supplies an increasing axial radius profile; the operation removes indexed
ring, seam, pole, cap and flat-normal construction work while retaining band/cell metadata
for styling. Root reviewed the six source boundaries, the accepted seven-image private
comparison and the explicit dependency admission. The selected boundary and exclusions
are in [the capability selection](../capabilities/cp7-profile-selection.md).

The catalog is the sole normative schema. Its required input fields, ordered topology,
complete static validation, preallocation face bound, stable dynamic errors, owned data
and atomic access rules follow the reviewed drafting worksheet. No presets, artistic
defaults, smooth normals, source RNG, renderer state or source-pixel claims were added.
The count proof establishes representability, not heap availability. Per-edge and cross
scaling preserve the demonstrated extreme-scale cases; rounded degeneracy still fails.

The shared generator derives 43 cases directly from the oracle and interval source
modules: 24 successes and 19 declared errors. It asserts the selected exact error codes
and first failing stages, oracle/interval topology and value correspondence, unchanged
side data under cap toggles, and unchanged geometry under ignored pole flags. It binds
the raw catalog and all generating sources. The fixture policy defines per-component
allowances separately from exact topology, reference bits and same-runtime replay.

Root read the generator and structural checker and corrected unchecked reference
correspondence, malformed-input continuation, count mismatch work, and dynamic capacity
precedence. The runtime comparator separately rejects shortened allowance arrays,
boolean indices, negative allowances, nonfinite values and negative zero. The staged
checks passed all 43 records, 14 structural mutations, 22 runtime-output mutations and
120 bounded trigonometric perturbations. These are scoped fixture checks, not evidence
that every host transcendental lies within the selected envelope.

Before delivery, Java must pass these shared vectors, same-runtime replay, input/output
detachment, indexed access and atomic buffer tests, explicit error precedence and bounded
performance checks. Then the installed Processing starter must demonstrate the meaningful
profile, subdivision, closure and styling edits under an explicit P3D lifecycle plan.
The private accepted renderer is immutable evidence and must not be rerun as though it
were the public implementation. Other platform ports remain deferred and unvalidated.
