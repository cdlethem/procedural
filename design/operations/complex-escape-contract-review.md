# Complex escape-time contract review

Root freezes the `complex.escape-distance-2d` contract for the second I-family slice.
The family design proposal (`.work/expansion-full/i-family-design.md`) and this review
record the frozen choices before implementation; the shared exact-json fixtures contain
only exact outputs and error codes, none generated by the implementation under test.

Resolved choices:
- One bounded operation, `complexEscapeDistance2D`, a pure function of its input that
  streams each pixel's orbit and returns two detached buffers: the escape count and the
  distance estimate. No persistent state, no materialized orbit.
- Mapping `mandelbrot` samples `c` from the world grid with `z_0 = 0`; mapping `julia`
  samples `z_0` from the world grid with a fixed constant `c`. The escape radius is fixed
  at `2` (the `z -> z^2` basin-of-infinity threshold); it is not a parameter.
- Iteration: `z_{k+1} = z_k^2 + c`, escaping at the first `k` with `|z_{k+1}| > 2`. The
  escape count is the number of `z` updates before escape, or the full budget if the
  orbit never escapes (interior). The count is a safe integer in `[0, iterations]`.
- Derivative recurrence, frozen per mapping: Julia starts `zder_0 = 1` and accumulates
  `zder_{k+1} = 2*z_k*zder_k`; Mandelbrot starts `zder_0 = 0` and accumulates
  `zder_{k+1} = 2*z_k*zder_k + 1` (the `+1` from the explicit `c`). The update uses the
  pre-update `z_k` and is ordered `zder` then `z` each step.
- Distance estimate for an escaped pixel: `log(|z|) * |z| / |zder|` using the escaped
  `z` and the accumulated `zder`, with the complex magnitude the Euclidean norm and the
  natural logarithm. An interior (non-escaped) pixel carries distance `0`. The estimate
  is a binary64 value; `NUMERIC_OVERFLOW` is reserved and defensive because a valid
  escaped orbit has `|z| > 2` and a generically nonzero `zder`.
- Work is `iterations * width * height` pixel-orbits in exact integers, precharged before
  allocation; the per-pixel orbit is bounded by `iterations` and does not grow with the
  grid. A `WORK_LIMIT` breach is atomic, with no partial buffer.
- The world grid is an axis-aligned cell grid: pixel `(i, j)` maps to the complex point
  `(origin.x + i*cell.x) + (origin.y + j*cell.y) * i`. `cell` is strictly positive in
  both axes; the grid size is a safe integer at most `2^32 - 1`.

Fixtures distinguish a known single-constant Julia escape count and distance, the
Mandelbrot interior (full budget, zero distance) and an escaped Mandelbrot point, the
escape-count boundary at the escape radius, the mapping-dependent derivative (Mandelbrot
`+1` vs Julia pure product), and the INVALID_INPUT/WORK_LIMIT carriers. This contract
freeze permits implementation; it is not native, artist recreation or target-support
acceptance.
