# Parameter adjudication queue

These are decisions to investigate, not public defaults, ranges, or contracts. Use the
parameter-evidence skill before exposing or documenting an insufficiently supported control.
Resolve the specific question from current evidence first; request bounded experiments only
when their outcome could change a decision. Do not wait for more reports by default.

Every completed adjudication must record the cluster and candidate IDs, note/result hashes,
verified parameter-to-variant associations, reliability, and separate exposure/default/range/
hard-bound outcomes. Link it from the eventual catalog entry; do not duplicate a second set
of public bounds here. None of these investigations authorizes a render outside the shared
pausable executor or modification of the survey/source corpus.
