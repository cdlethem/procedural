# I1 first-slice acceptance

Root accepts the scoped I1 milestone after Sol's final independent distribution review
on2026-09-07. The first dependency-complete composition has the three implemented public
operations, four scoped native drawing integrations, editable examples, and local artifacts
with verified consumer paths. The current survey remains826/901; missing reports do not
block this explicitly authorized slice.

| Target | Delivered artifact and consumer proof |
|---|---|
| Processing desktop | Core and separate desktop-adapter JARs inside a Processing library ZIP. Its extracted command starter passes official PDE preprocessing/compilation and four exact CP1 model/geometry/colour/count comparisons, with all three operations and the adapter loaded from those JARs. |
| JavaScript/p5 | Local npm tarball and starter ZIP with lockfile. The starter installs that tarball and pinned p5, loads its public operations, copies three internal adapter files byte-identically from the installed artifact, resolves its module graph and serves matching file bytes from its own server. |
| Python/py5 | Wheel and starter ZIP bundling that wheel. A separate environment installs the declared py5 extra and loads the extracted starter plus installed adapter, checks py5's exact version, and writes to a project-local output path. Staging preserves the FieldMarks class AST and mark-field source. |
| Processing Android | Separate core and adapter JARs plus clean Gradle starter ZIP. The extracted project contains exactly four example Java sources, consumes those JARs, and compiles an APK with the externally supplied pinned runtime. Build/cache/key/runtime-core files are excluded from the ZIP. |

The five generated reports under `evidence/distribution/` preserve source/runtime bindings,
artifact hashes, included-file manifests and consumer results. Root verified the final
bindings and archive manifests; Sol independently rechecked all71 recorded source/input
bindings, artifact hashes, Java verifier/CP1 bindings, shared Java/Android core JAR identity,
and retained APK notices. All reports pass with no pending consumer checks. All75 repository
tests pass. `docs/installing.md` gives the artifact and starter entry points.

This installation evidence complements the accepted native reviews in
`catalog/drawing/fresh-raster-2d.json`; it does not replace or broaden them. No passing
native renderer suite was repeated for packaging metadata. The new Java starter's commands
are equivalent to the accepted CP1 command route; its packaged compilation and command
checks are not represented as a new GUI execution.

The accepted claim is local artifact install/build/import consumption for version0.1.0,
with the already recorded scoped native evidence. Internal adapters remain versioned
starter implementation, not stable public APIs. This does not establish registry
publication, full-corpus reproduction, other platforms/devices, or a human twenty-minute
installation study. Those limits remain explicit rather than becoming new I1 blockers.

Proceed to I2: integrated paths as the next artistic capability, followed by deliberate
rare-family expansion and the downstream recipe/export/documentation/MCP/web milestones.
The full project objective remains incomplete. Future changed implementations require
their affected conformance and artifact evidence to be refreshed.
