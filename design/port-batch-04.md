# I2 port batch 04: retained endpoint branches

Start implementation after batch03 triangle distributions are accepted. This packet ports
`topology.seeded-endpoint-branches-2d` and the accepted BranchMarks workflow. It adds no
new Java operation or parameter range. Root remains the contract and integration owner;
Sol review stays paused. Use one bounded target implementation assignment at a time,
starting with JavaScript, then Python, then unchanged Java core execution on Android.

The artist supplies a root and ordered generation rules, retains the resulting tree,
and draws its segments with access to ancestry, generation, nominal length and terminal
membership. BranchMarks must preserve the distinction between changing growth rules and
changing the appearance of retained branches, plus transfer to multiple placed roots.
CutBranchMarks is a separate mutable line-pool capability and is outside this packet.
Do not merge endpoint branching with symbolic L-systems, interior cuts or generic growth.

Read the complete frozen catalog, all shared fixture sections, Java BranchTree2D and
BranchComposition, and the accepted CP6 contract/review before implementation. The catalog
is authoritative; the earlier private investigation documents do not override it.
In particular preserve breadth-first append order, actual direct child counts, root-only
behavior, shared per-parent length scale, gate/angle draw ordering, constant-interval draws,
and maxSegments failure before successful-child arithmetic. Extending generation rules
preserves earlier geometry and ancestry, but can change child counts and terminal status.

Keep passive host carriers, detached owned storage, atomic indexed access, validation/error
precedence, canonical zero and overflow stage metadata. The private stream and nominal
lengths/headings are exact. Host sin/cos coordinates follow the existing case-specific
cross-target tolerance policy; do not require universal trig bits or loosen fixtures after
observing a failure. Reuse reviewed stream/interpolation patterns without introducing a
new public RNG dependency or copying unrelated source-sketch machinery.

Luna/Terra own frozen-contract implementation, fixture execution and routine native-example
work. Root reviews numeric/error boundaries and full fixture coverage, then native images
and artist edits. Port the complete retained-tree interface, not merely enough segments
to draw the starter. Use the established result ownership/access harnesses and native
runtime environments. No new renderer framework or broad performance sweep by default.

Before each native workflow, preregister the smallest set covering growth depth/rules,
retained style/terminal treatment, multiple-root transfer, reset and cached save. Preserve
actual native lifecycle checks on Android and use the shared machine render lock. Freeze
each target's sources before rendering. Core, native, technique and package claims remain
separate; no original-sketch recreation claim follows from a starter render.

Close the batch with installed package consumers and root-reviewed evidence. Six operation
ports remain after triangle packaging; this packet completes one of those six. Radial
profile meshes, Delaunay, target springs, occupied lattice paths and mutable line pools
remain later bounded packets, followed by the remaining roadmap milestones. Do not expand
this packet while debugging it or call the overall project complete when it closes.
