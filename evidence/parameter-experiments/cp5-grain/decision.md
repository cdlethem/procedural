# CP5 private grain experiment decision

Root accepts the seven-image experiment as evidence for retained triangle point batches
and independent content, with a styling limitation on the multi-region transfer.

The first-vertex-biased mode is visibly distinct from uniform coverage. The puntis3 pattern
is also distributionally distinct, supported by numerical concentration and second moments;
it must not inherit a uniform label. Similar image-wide difference scores for these modes
do not imply equivalent spatial behavior.

The fixed triangle uses 15,680 centres (density 0.1); the density edit uses 31,360
(0.2). The transfer uses 40,960 across 26 triangles from 13 CP4 cells. Counts and triangle
containment passed. Recolour/strokes retain the exact baseline point object and hash;
the larger uniform count retains its prefix. These are discrete investigation settings,
not measured source ranges or defaults.

Root inspected every original PNG. `root-review.json` records observations and hashes.
The baseline and transfer are deliberately pale. The stroke variant shows that mark shape
can make the same retained geometry much more legible; public teaching should make that
substitution easy and use a clearer transfer palette. This does not justify adding opacity,
colour or mark size to the sampler.

One native batch passed without stderr. Two earlier preflight stops consumed no native
attempt: the final worker clarification changed a hash, then placed descriptive metadata
inside the boolean-check object. Root reviewed the final text and moved that description
outside checks. `execution-review.json` preserves this history. No sampling algorithm or
visual threshold was adjusted after rendering.

Next root decision: choose a convenient seeded batch and a clean distribution substitution
boundary. The first-point helper alone remains insufficient for the delivered workflow.
Avoid baking whole-sketch presets into the library or presenting a private sampler as a
public implementation. The current provisional triangle ledger still requires explicit
revision and contract review before code.

No API default, encouraged interval, hard limit or renderer support beyond this private
JAVA2D experiment is established. Source sketches, fixed inputs, exact hashes and scopes
are recorded by experiment.json, the grain audit and the separate numeric diagnostic.
