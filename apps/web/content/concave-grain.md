# Concave grain

A notched silhouette exposes deterministic triangulated grain. This is an original design study, not a recreation of a surveyed original.

| Control | Visible effect |
| --- | --- |
| Grain lines | Changes the study's structural composition. |
| Palette | Recolors the same geometry. |
| Reset | Restores the baseline composition. |

Uses `geometry.triangulate-simple-polygon-2d` in the Shapes & space study family.
