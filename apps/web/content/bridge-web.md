# Bridge web

Seven authored strands receive one selected bridge per logical tick. Each graph insertion returns stable split/link ancestry; the browser study colors current strand and bridge edges from that retained graph.

| Control | Canvas effect |
| --- | --- |
| Bridges | Replays more candidate insertions from the same initial strands. |
| Strain | Waves the authored strands; zero reads as a straight ladder, high strain wanders. |
| Slant | Sets the base candidate slant; negative values take the cross route. |
| Stride | Steps the gap selection; the common divisor with the six gap slots chooses how many gaps share bridges. |
| Candidate guide | Shows or hides the next proposed segment without editing the graph. |

The adapter calls `insert-segment-bridge-2d` for each step and carries its graph forward. The strand schedule and candidate schedule are editable example geometry. It is not a road-layout generator or an automatic face finder.
