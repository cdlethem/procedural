# Terraced islands

Nested hulls create stepped island perimeters. This is an original design study, not a recreation of a surveyed original.

| Control | Visible effect |
| --- | --- |
| Terraces | Changes the study's structural composition. |
| Palette | Recolors the same geometry. |
| Reset | Restores the baseline composition. |

Uses `geometry.convex-hull-2d` in the Layouts study family.
