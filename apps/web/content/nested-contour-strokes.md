# Nested contour strokes

Repeated offsets turn one boundary into layered contour ink. This is an original design study, not a recreation of a surveyed original.

| Control | Visible effect |
| --- | --- |
| Rings | Changes the study's structural composition. |
| Palette | Recolors the same geometry. |
| Reset | Restores the baseline composition. |

Uses `geometry.offset-polyline-2d` in the Shapes & space study family.
