# Flowing brushes

Chaikin refinement turns angular rows into flowing ink ribbons. This is an original design study, not a recreation of a surveyed original.

| Control | Visible effect |
| --- | --- |
| Rows | Changes the study's structural composition. |
| Palette | Recolors the same geometry. |
| Reset | Restores the baseline composition. |

Uses `geometry.chaikin-polyline-2d` in the Fields & paths study family.
