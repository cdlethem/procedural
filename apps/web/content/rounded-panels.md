# Rounded panels

Rounded Chaikin-cut panels make a quilt of softened square routes.

| Control | Visible effect |
| --- | --- |
| Panels | Changes the study's structural composition. |
| Palette | Recolors the same geometry. |
| Reset | Restores the baseline composition. |

Uses `geometry.chaikin-polyline-2d` in the Shapes & space study family.
