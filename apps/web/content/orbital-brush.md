# Orbital brush

Resampled closed paths gather around three quiet centres. Draw them as ribbons or beads without changing the current path samples. This is an original study, not a recreation of a surveyed artwork.

| Control | Canvas effect |
| --- | --- |
| Brush treatment | Draws the same retained samples as ribbons or separate beads. |
| More paths | Rebuilds the bounded family with additional closed paths and samples. |
| Palette | Recolors the existing path record. |

The shared motif helper builds each closed path with the accepted polyline-resampling operation.
