# Gesture skeletons

Simplified gestures retain a visible set of decisive joints. This is an original design study, not a recreation of a surveyed original.

| Control | Visible effect |
| --- | --- |
| Gestures | Changes the study's structural composition. |
| Palette | Recolors the same geometry. |
| Reset | Restores the baseline composition. |

Uses `geometry.simplify-polyline-2d` in the Fields & paths study family.
