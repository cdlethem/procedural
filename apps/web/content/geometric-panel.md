# Geometric panel

An offset grid holds an asymmetric field of wedges or crossed bars.

| Control | Canvas effect |
| --- | --- |
| Mark treatment | Replaces wedges with bars at the same retained grid anchors. |
| Tight grid | Rebuilds the bounded regular-grid record with more rows and columns. |
| Palette | Recolors the panel without moving its current anchors. |

The layout comes from the shared motif composition helper, which calls the accepted regular-grid operation.
