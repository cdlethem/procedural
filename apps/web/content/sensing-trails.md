# Sensing trails

Seventy-two marks steer through an authored scalar field using paired left and right probes. Each field choice replays explicit logical steps from the same initial population.

| Control | Canvas effect |
| --- | --- |
| Ticks | Extends the sampled trails through deterministic sensing steps. |
| Field source | Moves the field's two bright attractors. |
| Turn gain | Changes signed response to right-minus-left probe values. |
| Dot marks | Stamps retained trail samples instead of joining paths. |

`sensor-motor-step-2d` computes probe samples, heading, and movement. The grid and mark treatment are explicit example choices; no deposition or hidden field evolution occurs.
