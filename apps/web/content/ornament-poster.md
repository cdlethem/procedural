# Ornament poster

A retained packed field carries petals, leaves, or abstract emblems around an authored title block. This is an original study, not a recreation of a surveyed artwork.

| Control | Canvas effect |
| --- | --- |
| Motif | Replaces the marks while retaining every accepted placement anchor. |
| Tiered scale | Changes the independent size hierarchy at those anchors. |
| Crop | Changes the framed portion of the same arrangement. |
| Dense layout | Rebuilds the circle-placement record with its alternate bounded input. |
| Palette | Recolors the retained composition. |

The study calls circle placement through the shared motif composition helper. Its marks and text treatment remain ordinary p5 drawing choices.
