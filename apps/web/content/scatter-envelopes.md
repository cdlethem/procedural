# Scatter envelopes

A convex hull frames a varied field of source sites. This is an original design study, not a recreation of a surveyed original.

| Control | Visible effect |
| --- | --- |
| Sites | Changes the study's structural composition. |
| Palette | Recolors the same geometry. |
| Reset | Restores the baseline composition. |

Uses `geometry.convex-hull-2d` in the Layouts study family.
