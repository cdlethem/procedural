# Road margins

Paired offsets make route margins with visible join behavior. This is an original design study, not a recreation of a surveyed original.

| Control | Visible effect |
| --- | --- |
| Margin | Changes the study's structural composition. |
| Palette | Recolors the same geometry. |
| Reset | Restores the baseline composition. |

Uses `geometry.offset-polyline-2d` in the Fields & paths study family.
