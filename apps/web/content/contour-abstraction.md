# Contour abstraction

One sampled contour becomes a stacked family of simplified lines. This is an original design study, not a recreation of a surveyed original.

| Control | Visible effect |
| --- | --- |
| Tolerance | Changes the study's structural composition. |
| Palette | Recolors the same geometry. |
| Reset | Restores the baseline composition. |

Uses `geometry.simplify-polyline-2d` in the Fields & paths study family.
