# BranchMarks py5 example

This validated py5 workflow draws retained endpoint trees from `branch_composition.py`. In the
prepared checkout, run it with JDK17 and the pinned py5 environment on a display. Native
callback/raster workflow is accepted; standalone packaging remains pending.

R changes seed; N appends/removes a fixed generation; G narrows the fixed spread schedule;
W widens it; B switches two/three slots; and X transfers roots to CP3 circle placements.
M toggles nominal-length taper plus actual terminal dots, C changes palette, 0 resets, and S
saves the shown canvas under `output/`. M/C retain the same composition; growth controls rebuild.
Q is ignored. Forest placement reserves root space rather than separating canopies.

Lines use retained segments, generation colour capped at generation/2, and `child_count_at(i)`
for actual tips. `JFloat` carries the Java renderer boundary conversion; it does not claim
cross-renderer pixel identity. The rule schedule, roots, colours and marks are editable example
choices, not library defaults or measured recommended ranges. Motivation is
`survey/out/2018/Generativos/arbolito3/notes.md` and `arbolito4/notes.md`.
