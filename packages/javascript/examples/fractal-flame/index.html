PROCEDURAL / FRACTAL FAMILIES

Fractal Flame

A weighted set of contractive maps iterates a seeded point process, and the accumulated density is exposed with a logarithmic ramp. Variation nudges the authored maps into neighboring flames; exposure and ramp are presentation and never resimulate the point sequence.

Edit the transform matrices, powers, weights, seeds, budget or density window in sketch.js. The iteration and the bilinear accumulation are one portable operation.
