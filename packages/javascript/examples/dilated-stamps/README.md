# Dilated stamps

An original editable p5 study. Serve this directory so `/p5.js` is available and open `index.html`.

| Control | Effect |
| --- | --- |
| T | Applies the structural edit. |
| C | Changes the packed RGB palette. |
| 0 | Restores the baseline. |
| S | Saves the canvas as PNG. |

The synthetic raster is computed through [`binary-morphology-2d`](../../../catalog/operations/binary-morphology-2d.json). Edit `../materials-a-studies.js` to change the visible input field or drawing; this example makes no native-support claim.
