# Cell mosaic

Colored nearest-site tiles form a faceted mosaic with fine open seams. Serve this directory from the project’s p5 example server, which provides `/p5.js`, then open `index.html`. Edit `expansion-studies.js` to change the site layout, tile treatment, or palette.

| Control | Canvas effect |
|---|---|
| T | Changes the number of generated cells. |
| C | Changes the tile palette. |
| 0 | Restores the initial composition. |
| S | Saves the current canvas as PNG. |

Uses `geometry.voronoi-cells-2d`. This independent design is admitted in `design/capabilities/p5-gallery-expansion.md`.
