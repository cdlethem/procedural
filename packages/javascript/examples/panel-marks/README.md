# Panel marks in the browser

This source-checkout starter retains a 60×60 integer cell grid cut into ordered
panels by `layout.binary-cell-partition-2d`, drawn either as nested inset outlines
per cell or as solid tinted panels. Attempt count (80/240/20) and axis policy
(longest-side/random) rebuild the retained layout; palette and decoration are
sketch-only drawing choices.

This starter is not a browser-native conformance or reproduction claim; it is a
scoped port of the accepted PanelMarks composition's mechanism (CP17) to p5.js.
