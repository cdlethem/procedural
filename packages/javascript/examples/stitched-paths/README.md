# Stitched paths

Rows of short cross stitches follow colored wave paths at equal traveled distances. Serve this directory from the project’s p5 example server, which provides `/p5.js`, then open `index.html`. Edit `../cell-mosaic/expansion-studies.js` to change the supplied waves, stitch marks, or palette.

| Control | Canvas effect |
|---|---|
| T | Changes the wave count. |
| C | Changes the thread palette. |
| 0 | Restores the initial composition. |
| S | Saves the current canvas as PNG. |

Uses `geometry.resample-polyline-2d`. This independent design is admitted in `design/capabilities/p5-gallery-expansion.md`.
