# Contour blobs

Nested contours wrap around and merge across a field of soft seeded hills. Serve this directory from the project’s p5 example server, which provides `/p5.js`, then open `index.html`. Edit `../cell-mosaic/expansion-studies.js` to change the hill field, contour treatment, or palette.

| Control | Canvas effect |
|---|---|
| T | Widens the generated hills. |
| C | Changes the contour palette. |
| 0 | Restores the initial composition. |
| S | Saves the current canvas as PNG. |

Uses `geometry.marching-squares-2d`. This independent design is admitted in `design/capabilities/p5-gallery-expansion.md`.
