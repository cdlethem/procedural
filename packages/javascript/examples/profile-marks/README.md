# Profile marks

Serve this directory with the repository p5 harness. `profile-marks.js` owns the editable 17-point cylinder, waist and pointed example forms. `sketch.js` maps them to explicit centred p5 WEBGL camera and lighting settings, consumes retained triangles and supplied flat normals, and saves the last acknowledged canvas image.

P, D, B and T select profile or rebuild geometry; C and X change appearance or arrangement while retaining the same composition. These example settings are not radial-profile presets or recommended ranges.
