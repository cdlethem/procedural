Landscape marks

A P2D recreation of Manolo ide's parapara. A seeded policy combines a gradient-noise horizon, layered cyclic-palette stripes, accepted ordered circle placements, and Delaunay facets into a compact landscape.

Building the landscape…

C shifts the palette; P switches from eased to uniform stripe spacing; R makes a new seed and regenerates its field, placements, mesh, and mark policy; 0 restores seed 42; S saves the cached canvas without redraw. This is a structural recreation: the same Java composition pipeline is used, not a pixel-identical browser claim.
