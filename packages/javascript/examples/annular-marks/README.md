# Annular marks in the browser

This source-checkout starter retains a closed annular solid mesh (outer wall,
inner wall, top and bottom annulus) generated by `mesh.annular-solid-3d`, lit and
drawn either as a single rotated instance or a rotated triple arrangement with
per-instance recoloring. Cross-checked the mesh's face count, per-face kind,
normal, triangle, and vertex data against a real `AnnularMesh3D` Java reference
run before writing the JS model test (384 faces, byte-identical face 0 data).

Platform note: Processing's P3D renderer keeps `(0,0)` at the canvas's top-left
corner; p5's WEBGL renderer centres the origin instead, so the single-instance
mode's Java recentring translate is dropped and the triple arrangement's absolute
instance positions are converted accordingly.

This starter is not a browser-native conformance or reproduction claim; it is a
scoped port of the accepted AnnularMarks composition's mechanism to p5.js.
