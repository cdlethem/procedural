Retain a closed annular solid mesh (outer wall, inner wall, top and bottom annulus), lit and drawn single or as a rotated triple arrangement.

Edit the composition in annular-marks.js: the width, depth, and facet-count toggles rebuild the retained mesh; the sketch's single/triple arrangement and per-kind palette are the place to invent another treatment of the same mesh. These values describe this piece. Platform note: Processing's P3D keeps (0,0) at the top-left corner; p5's WEBGL renderer centres the origin, so the single-instance mode's Java recentring translate is dropped and the triple arrangement's absolute instance positions are converted accordingly.
