# Organic cells

Life-like organic cells. Serve the p5 examples and open `index.html`. Edit `../systems-a-studies.js` to change the supplied simulation inputs or drawing.

| Control | Effect |
| --- | --- |
| T | Applies a structural edit. |
| C | Changes palette. |
| 0 | Resets. |
| S | Saves PNG. |

This is an original editable study and does not claim native support.
