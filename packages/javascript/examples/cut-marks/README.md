# Cut marks in the browser

This source-checkout starter retains caller-directed unequal rectangle regions with
stable never-reused identities (`layout.retained-rectangle-cuts-2d`). A seeded 12-cut
initial setup (aligned or staggered Y-ratio policy, optional hole removal) builds the
starting layout; click a region to select it, then cut it at its midpoint on X or Y,
or remove it, all through the same atomic single-edit API an artist would use live.

This starter is not a browser-native conformance or reproduction claim; it is a
scoped port of the accepted CutMarks composition's mechanism to p5.js.
