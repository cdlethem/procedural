# Branching networks

Seeded depth-first branching grid networks. Serve the p5 examples and open index.html. Edit ../systems-b-studies.js to change the supplied operation inputs or drawing.

| Control | Effect |
| --- | --- |
| T | Applies a structural edit (Rows: 13 to 20). |
| C | Changes palette. |
| 0 | Resets. |
| S | Saves PNG. |

This is an original editable study and does not claim native support.
