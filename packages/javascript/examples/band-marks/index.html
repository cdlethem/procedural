Band marks

Retain 64 attempt-bounded noise-band paths in an 8x8 grid, then draw either their connected movement or a perpendicular tick every 8th vertex. Style edits reuse the same paths.

Preparing paths…

Edit the composition in band-marks.js: the start grid, seeds, field scale/offset and tolerance rebuild the retained paths; bandPathCommands() is the place to invent another treatment of the same paths. These values describe this piece.
