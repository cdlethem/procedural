# Cell echoes

Nested colored outlines recede toward the centers of irregular cells. Serve this directory from the project’s p5 example server, which provides `/p5.js`, then open `index.html`. Edit `../cell-mosaic/expansion-studies.js` to change site placement, echo treatment, or palette.

| Control | Canvas effect |
|---|---|
| T | Adds nested outlines. |
| C | Changes the outline palette. |
| 0 | Restores the initial composition. |
| S | Saves the current canvas as PNG. |

Uses `geometry.voronoi-cells-2d`. This independent design is admitted in `design/capabilities/p5-gallery-expansion.md`.
