# Woven grammar

Parallel grammar paths woven into a square pattern. Serve the p5 examples and open index.html. Edit ../systems-b-studies.js to change the supplied operation inputs or drawing.

| Control | Effect |
| --- | --- |
| T | Applies a structural edit (Angle: 60 to 38). |
| C | Changes palette. |
| 0 | Resets. |
| S | Saves PNG. |

This is an original editable study and does not claim native support.
