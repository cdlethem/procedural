Procedural / retained image

Feedback Print

Ink petals echo across paper. Each step reads the retained print through a small affine shift, fades it, and layers a fresh motif.

Preparing…

Press Space for one step, W for warp, D for fade, M for motif, 0 to reset, S to save.

ControlCanvas effect
WarpChanges how the retained pixels are sampled on subsequent steps.
FadeChanges how quickly earlier ink loses opacity.
MotifChanges the fresh petal and dot drawing while retaining the current print.
Reset / SaveClears both history buffers / downloads the displayed print.

Original example. Edit study.js to change the motif, affine transform, and timing. The controls are example choices, not measured recommended ranges. The broader retained-image task is motivated by the Davis audiovisual and Levin video systems in the external corpus family 25.
