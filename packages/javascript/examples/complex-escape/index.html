PROCEDURAL / FRACTAL FAMILIES

Complex Escape

One bounded operation iterates the quadratic map z -> z^2 + c over the sampling window and returns a per-pixel escape count plus a derivative distance estimate. The Mandelbrot view samples the constant over the plane; the Julia view samples the start point for a fixed constant. Two colorings show the two outputs: glow maps the distance estimate to a warm ramp, and bands cycles the escape count across the budget so the bands accumulate at the boundary. Zoom and pan move the window, the budget sets escape depth, and the Julia constant picks the set.

Edit the Julia constants, the default view windows, the budgets or the ramps in sketch.js. The iteration and the distance estimate are one portable operation; high-zoom precision and filtering are separate limits.
