Path clip marks

Build rows, wandering paths or a fan, then keep only the marks inside an editable boundary. Move or reshape the boundary without changing the source family. The light canvas color is a page preview; exported pixels outside the marks are transparent.

Preparing clipped paths…

Bottom portal and right bay modes inset one edge. An opening wider than that edge or a cut through the entire shape is rejected because it cannot describe the requested simple boundary. Zero opening or depth gives a rectangle.
