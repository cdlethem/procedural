Pointer marks

Forty-nine spring bodies on a fixed grid drift back toward their start positions; press and drag inside the canvas to pull nearby targets toward the pointer. The wire mode draws the fixed initial Delaunay connectivity transferred to the moving bodies.

Preparing bodies…

Hold the pointer inside the canvas while running to drag nearby bodies; release to let them relax back. Edit the composition in pointer-marks.js: the return rate, pointer radius and pull rate shape the response, and the grid, palette, and draw modes are the place to invent another treatment of the same springs. These values describe this piece.
