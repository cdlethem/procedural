# Turtle canopies

Explicit recursive turtle canopies. Serve the p5 examples and open index.html. Edit ../systems-b-studies.js to change the supplied operation inputs or drawing.

| Control | Effect |
| --- | --- |
| T | Applies a structural edit (Depth: 5 to 6). |
| C | Changes palette. |
| 0 | Resets. |
| S | Saves PNG. |

This is an original editable study and does not claim native support.
