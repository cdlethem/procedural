City marks

A structural recreation of Manolo ide's ciscis002: a seeded quadrant partition supplies building sites, Delaunay triangulation turns them into a mesh of building footprints, and one java.util.Random-driven policy assigns each building a height, a cyclic-palette color, a ground tone, and hundreds of individually lit or dark windows.

Building the city…

C shifts the palette; H toggles between tall and low building heights; R generates a new seed (a fresh partition, mesh, and building policy); 0 resets to seed 42; S saves without redraw. This is a structural recreation - the same generation pipeline and building count as the Java source, not a pixel reproduction claim. Each window box is drawn as its two largest (front/back) faces rather than all six, a rendering accommodation for WebGL immediate-mode performance at this object count (hundreds of thousands of windows); position, size, count, and lit state are unaffected.
