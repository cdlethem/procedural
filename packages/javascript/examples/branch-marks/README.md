# BranchMarks p5.js example

This browser example draws the reviewed retained endpoint-branch composition. It expects a
localhost server that serves repository modules and pinned p5 at `/p5.js`; standalone
packaging and native browser acceptance are pending.

R changes seed, N appends/removes one fixed generation, G narrows the fixed spread schedule,
W widens it, B selects two or three slots, and X transfers roots to CP3 circle placements.
M toggles line taper plus actual retained terminal dots, C changes palette, 0 resets and S
saves the cached displayed canvas. M/C retain the composition; geometry controls rebuild it.

Lines use retained segments and are coloured by absolute generation, capped at generation/2,
so appending a generation does not recolour earlier segments. Taper uses each retained nominal
length and actual `childCountAt(i) == 0` marks tips. The browser drawing carries Java's float
boundaries with `Math.fround`; it is not a cross-renderer pixel-identity claim.

The composition is independently specified from public cores and is motivated by
`survey/out/2018/Generativos/arbolito3/notes.md` and `arbolito4/notes.md`. Rule schedules,
root placement, colours and mark dimensions are editable example choices, not library defaults
or measured recommended ranges.
