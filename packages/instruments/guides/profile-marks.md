# Profile marks — Revolved Profiles

Build pinched columns, flared profiles and open wire shells by editing the form's silhouette.

Edit the **Axial profile** itself: one `axial position, radius multiplier` pair per line, in strictly increasing axial order. The retained `RadialProfile3D` source revolves those knots about its Z axis. Axial position and radius multiplier are dimensionless (not confined to 0–1); the axial position is mapped to `(position − 0.5) × Axial scale` and the radius to `multiplier × Radial scale`. Values outside 0–1 make intentional overhangs or off-center forms, not an automatic fit. A profile is a piecewise-linear surface between knots, not a smoothing spline. Profile marks and Depth marks share precisely this source and these visible controls; switching presets only changes the starting parameter recipe.

| Controls | Canvas effect |
| --- | --- |
| Axial profile | 2–48 ordered pairs; position −8…8, radius 0…8. Interior radii must be positive. The first/last radius may be zero for a pole, but two zero poles cannot be the only two points. Lines are never sorted silently. |
| Axial scale, Radial scale | Positive canvas-unit scales (.001…1000), independent of the knot values; no fit-to-frame or camera adjustment. |
| Angular slices | 3–192 integer angular cells. Triangular face count is `slices × (2 × (knots − 1) − pole count + actual cap count)` and must not exceed 12,000. |
| Start cap, End cap | Independently close the first/last nonzero-radius ring. A zero-radius pole is already closed by the side triangles; its cap switch adds nothing. |
| Offset X/Y | Set mesh center on the 640×640 canvas; values −10,000…10,000 can place the mesh off paper. |
| Yaw, Pitch, Roll | Rotate about Y, X, Z respectively, in degrees (−36,000…36,000); no camera auto-fit. |
| Faces, Edges, Edge weight | Independently show shaded triangles and distinct indexed triangle edges. Weight .01…30 affects edges only. Both switches off produce no ink. The wireframe includes triangulation diagonals. |
| Palette mapping, palette | Solid uses the first swatch; Band maps actual radial source bands (and start/end caps) into palette indexes; Angular maps actual angular cell indexes; Noise maps local 3D face-center samples through the palette. Colors cycle for band/angular, and noise samples choose swatches. |
| Noise scale, Noise depth offset, seed | Only Noise mapping uses these: scale .001…10,000 canvas units per 3D noise coordinate, depth −10,000…10,000 is an additive noise Z coordinate, not mesh depth. Seed changes this color field only; it cannot change the geometry or deterministic solid/band/angular colors. |
| Ambient light, Directional light, Light azimuth/elevation | Face lighting intensities 0…255 and light-vector heading/vertical inclination (elevation −90…90°). Edge strokes are unlit. |

Three contrasting starting experiments (values not mentioned stay at the current preset):

1. **Off-center open vase:** Axial profile `−0.25, 0.42` / `0.12, 0.95` / `0.52, 0.48` / `1.3, 0.85` (one pair per line), Axial scale 190, Radial scale 72, Start cap off, End cap off, Faces on, Edges off, Offset X 185, Offset Y 390, Pitch 78°, Yaw −25°. Bands expose the hand-drawn outline.
2. **Tipped wire funnel:** Axial profile `0, 0.9` / `0.25, 0.75` / `0.65, 0.32` / `1, 0`, Axial scale 270, Radial scale 105, Start cap off, End cap off, Slices 12, Faces off, Edges on, Edge weight 1.5, Palette mapping Angular, Roll 22°. The zero-radius tip is a genuine pole.
3. **Chromatic closed spindle:** Axial profile `0, 0.25` / `0.18, 1.15` / `0.54, 0.45` / `0.83, 1.1` / `1, 0.25`, Start cap on, End cap on, Faces on, Edges on, Slices 48, Palette mapping Noise, Noise scale 55, Noise depth offset 1.8. Only now does reseeding recolor the surface.

The geometry is an indexed radial surface generated by the released core. No thickness, volumetric fill, smoothing, shadow, or occlusion-aware removal of hidden wire edges is promised. Invalid knot order, scale, radius, integer slice count or face budget is an input error rather than repaired geometry.
