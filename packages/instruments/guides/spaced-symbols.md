# Spaced Symbols: Spaced Marks starting recipe

The Symbols starting recipe opens the same Spaced Marks Poisson-disc placement instrument as Stipple, with square marks and a larger spacing initially. The source first samples a rectangle at its real width and height; ellipse and annulus are acceptance filters, not a distortion of site distances. The source cap counts candidates before filtering, so it is not a promise of visible marks. Mark, size, aspect, angle and seeded angle spread only change appearance, not site positions.

| Experiment | Settings | Result to look for |
|---|---|---|
| Open constellations | Ellipse; width 380, height 160; center (380, 225); spacing 35; cap 120; cross, size 17, aspect 0.4 | Separated linear marks with plenty of room for another layer. |
| Broken wreath | Annulus; opening 0.8; width 510, height 460; spacing 24; cap 240; short-stroke, size 20, aspect 0.7; angle 70°, spread 80° | Directional fragments around an empty center. |
| Compact emblem | Rectangle; width 95, height 70; center (600, 580); spacing 30; cap 40; diamond, size 12 | One small reusable patch, rather than a full-canvas pattern. |

Minimum separation applies to **centers**, not mark edges: large symbols can overlap intentionally. Zero size draws nothing. Exact entry permits separation 1–1600, footprint dimensions 1–1600, attempts 1–30 and cap 0–600; slider intervals are the more practical starting span. Cap × attempts must not exceed 18,000, and the sampling operation is bounded by 3,000,000 work units.
